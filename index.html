Dell Rclone Backup

Dell Rclone Backup is a personal backup solution for a privately owned Dell Latitude computer.

How it works

The application uses Restic and rclone to create encrypted backups and store them in the computer owner's Google Drive account.

Backup data is encrypted locally before upload. Google Drive OAuth authorization is used to access the owner's backup storage.

Availability

This application is intended for personal use and is not offered as a public backup service.
