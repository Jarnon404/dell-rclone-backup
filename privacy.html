Privacy Policy

Last updated: October 31, 2026

Purpose

Dell Rclone Backup is a personal application used to back up files from a privately owned Dell Latitude computer to the owner's Google Drive.

Google Drive access

The application uses Google OAuth authorization through rclone to access Google Drive. It can list, read, create, update and delete Drive files as permitted by the granted scope.

Data processing

Selected local files are encrypted using Restic before being transferred to Google Drive. Encrypted backup data is stored in the owner's Google Drive account.

Credentials

OAuth credentials and backup encryption credentials are stored locally on the owner's computer. They are not published on this website.

Sharing and retention

The application is not operated as a service for third parties. Backup data is not sold or intentionally shared with advertisers. The owner controls backup retention and deletion.

Security

The application uses Restic encryption and Google OAuth authentication. It does not guarantee absolute security or availability.

Contact

For questions about this personal application, contact the project owner through the GitHub project .
